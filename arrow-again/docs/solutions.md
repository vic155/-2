## 为什么贪心求解足够

每次消除只会删除一个箭头，不会移动其他箭头或新增阻挡。因此，原本可以消除的箭头，在删除别的箭头之后依然可以消除。若存在完整通关顺序，把当前任意一个可消除箭头提前删除，不会使后面的步骤失效。

`solve()` 在棋盘副本上反复寻找第一个可消除箭头并删除。棋盘变空说明有解；如果仍有箭头但全部被阻挡，当前局面就没有合法的下一步。该算法只适用于本作业的基础规则；加入移动机关等规则后需要重新分析。

## 复现验证

在项目根目录运行下列 Python 代码即可再次检查。开发中已执行等价代码，进程退出码为 `0`，三个关卡均通过断言。

```python
from arrow_game.levels import LEVELS
from arrow_game.model import Game, solve

for index, level in enumerate(LEVELS):
    game = Game()
    game.load_level(index)
    initial_count = len(game.available_moves())
    order = solve(level)
    assert order is not None
    assert len(order) == len(level.arrows)
    for position in order:
        assert game.click(*position).kind == "removed"
    assert game.status == "won"
    assert game.mistakes_left == 3
    assert not game.board
    print(index + 1, len(order), initial_count, game.status)
```
