# 第二版：随机出题与点击音效

## 新功能

- 保留三档难度，布局由 `generate_level()` 随机生成，并从构造过程保证可解。
- 开始游戏与进入下一关会出新题；`R` 重开相同题目，`N` 换一道同难度题。
- 新增按钮、消除、碰撞、通关与失败 5 种短音效。`M` 或顶部按钮开关音效。
- 没有音频设备、资源缺失或音频已关闭时安全降级，游戏逻辑继续运行。
- 沿用中文行尾注释，便于阅读关键代码。

## 文件关联

`main.py` 创建 `GameApp`。界面调用 `Game`，规则层通过 `levels.py` 生成与保存本题，再由 `find_blocker()` 检查每次点击。界面依据 `MoveResult.kind` 调用 `audio.py` 播放音效，并显示动画。`tools/build_sounds.py` 用标准库生成 WAV，正常启动直接加载随项目提供的资源。

## 验证与修正

56 项自动测试通过，其中随机题测试包含 300 题完整求解与点击回放。测试发现，在音频模块关闭后调用旧 `Sound` 对象可能直接导致进程退出，不能只依赖捕获 `pygame.error`；现先检查 `pygame.mixer.get_init()`，关闭后不再播放旧对象。对应回归测试通过。

界面截图和 GIF、Windows exe 随第二版重建；结果以 `test-results.txt`、`render-check.json`、`package-check.json` 为准。自动音频测试验证文件、播放通道和静音行为，实际听感仍需本人试听；GIF 本身没有声音。

## 音效调整

根据用户试听反馈，改用清脆的固定音高与快速衰减，减少低频和拖尾。消除为清亮的短叮声，碰撞为短促轻敲。已通过 4 项音频检查并重新打包；详细记录见 [audio-check.json](audio-check.json)。

## 主页与开场调整

主页改为居中标题、一个开始按钮和三个简短难度选项，删除版本字样及重复介绍。装饰箭头打开时归位、轻微浮动，点击可以飞出并返回，不改变关卡或失误次数。

进入棋盘时，箭头按行列错开时间轻落；约 0.62 秒的入场不计入用时。首次点击或提示会立即结束入场，操作无需等待。消除动画增加短尾迹。开场演示见 `images/opening.gif`，所有画面均由实际游戏采集。

新增 3 项界面交互检查，总计 56 项测试通过。
